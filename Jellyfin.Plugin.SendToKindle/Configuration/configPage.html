Send to Kindle

Configure the global SMTP settings used to send emails to Kindle devices. Users will configure their own Kindle Email Address via the context menu.

IMPORTANT: Amazon strictly requires the sending email address to be whitelisted on your Amazon account. You must go to your Amazon account settings ("Preferences" -> "Personal Document Settings" -> "Approved Personal Document E-mail List") and add the SMTP Username you configure below.
Example: smtp.gmail.com
Usually 587 or 465
Your email address
App password if using 2FA

DeDRM Settings

Comma-separated list of Kindle Serial Numbers (PIDs) used to decrypt DRM-protected Amazon books. (Required to send protected .azw3 or .mobi files)

Shelfmark Integration

Allow users to search and request books from a remote Shelfmark instance directly within Jellyfin.
The base URL of your Shelfmark instance (e.g. http://192.168.1.100:8084)
Static API key configured in Shelfmark.

Test SMTP Configuration

The email address to send a test message to.
