# Technology Stack

## Core Language & Runtime
- **C# / .NET:** The standard language and runtime for Jellyfin server plugins.

## Frameworks & APIs
- **Jellyfin Plugin API:** Utilized to integrate the plugin into the Jellyfin server ecosystem, manage configuration, and handle actions from the Jellyfin UI.

## Storage
- **Jellyfin Configuration (XML):** Plugin settings (like SMTP credentials and target Kindle emails) will be stored using Jellyfin's built-in plugin configuration management system. No external database is required.
