# Product Guidelines

## Voice & Tone
- **Technical and Direct:** All user-facing text, such as configuration descriptions and UI notifications, should be concise, objective, and clearly communicate the necessary information without unnecessary conversational filler.

## User Experience (UX) Principles
- **Minimalist Configuration:** The settings page should be streamlined, asking only for the essential fields required for SMTP setup and Kindle email delivery.
- **Unobtrusive Feedback:** Notifications should be clear but brief (e.g., "Book sent to Kindle", "SMTP Error: Check credentials"), relying on server logs for deeper troubleshooting details rather than cluttering the UI.
- **Native Integration:** Ensure the plugin configuration UI feels like a native part of the Jellyfin dashboard, adhering to standard Jellyfin component styles.
